Evaluating Cornerback Performance

Complete Design Process | Seasons 2020 – 2024

Project Overview

This article covers the design process for creating a model that evaluates cornerback performance. The model uses season-specific measurables, such as average interception rate, average passer rating, and more; and utilizes Principle Component Analysis (PCA) to create adaptive weightages using these measurables.

After filtering to cornerbacks that have played at least 13 games, 600 snaps, and have received at least 40 targets in a season, the model takes measurables for that season and returns a ranking of the best qualified cornerbacks from that season. The model was tested with seasons 2020 through 2024 and works effectively when tested on other seasons, such as 2019 and 2025.

Phase 1: Problem Definition

Cornerbacks are notoriously difficult to evaluate and are considered very differently than other positions, like quarterback and running back. A cornerback's performance is determined by two things, how often they get the ball and what they do when they get the ball.

The problem with using cumulative statistics like interceptions and pass deflections is that cornerbacks often have little control over these stats. What I mean by this is that quarterbacks decide where the ball goes, and if they choose not to throw to a certain cornerback, that corner will not get any interceptions or pass deflections.

After this insight, I framed the question in a different manner. Now the goal of this model was to see how cornerbacks perform when the ball comes there way, suggesting a per-target rate approach. This allows us to see the best coverage cornerbacks, regardless of their target rate.

Phase 2: Data Source Selection

A popular data source used by many football statisticians is nflfastR play-by-play data. The way that it works is for every pass play, the dataset tags the defending player via pass_defense_1_player_id and pass_defense_2_player_id columns. In theory, it would give us every target thrown at a CB on every play.

However, after significant testing with the data source, I found out that only 10.2% of regular season pass plays had a defender tagged; a defender is only tagged when an official NFL statistic is credited, like pass breakups and interceptions. This means we were once again measuring the number of impactful plays rather than the per-target rates.

The solution to this problem was using the PFR Advanced Defense Stats. Though nflfastR is a generally good data source, the PFR data source appealed to me because of its specificity on tracking defensive stats. PFR uses manual charting to track every targeted pass to a coverage defender, meaning that we had a way of looking at all targets now. This dataset contains targets, completions allowed, interceptions, touchdowns allowed, yards allowed, and passer rating allowed per player per season, making it perfect for the cornerback coverage model.

Phase 3: Feature Engineering

Now that we had the correct stats, the question arose regarding what per-target stats do we actually include? Additionally, how do we manipulate these stats to come up with a working model?

After significant testing with multiple combinations of features, I settled on the 5 features for this model: incompletion rate, interception rate, passer rating allowed (inverted), target rate (inverted), and yards per target (inverted and winsorized). Certain stats were inverted because, for example, a higher passer rating allowed signifies a worse cornerback and a lower passer rating allowed means a better cornerback. Yards per target was winsorized (split between 5th and 95th percentile) to prevent extreme outliers from distorting the model.

Phase 4: Qualification Filters

Before we use our model, we have to filter within the cornerbacks, to make sure that rankings are based on meaningful sample sizes and full-season performances. The filters chosen were 40 minimum targets, 600 minimum defensive snaps, and 13 minimum games played.

An interesting example that caused a lot of problems in my model was 2020 Bryce Callahan. For the 10 games he played that season, he allowed a very low yards per target rate and was consistently showing up at the top of the 2020 rankings. However, since he got injured, I realized it was unfair and not viable to have him as a qualified cornerback, resulting in the 13 game minimum for qualified cornerbacks.

Phase 5: Model Architecture

The first approach I attempted for this project was using LightGBM LambdaRank. The way this machine learning approach works is by manually assigning CB rankings and have the model create weightages for the features based on the rankings. After training this model on the 2020 to 2024 seasons, it worked pretty well, producing viable rankings for these seasons. However, since the weightages for the features were fixed, they did not translate well when testing with other seasons, such as the 2019 and 2025 seasons. This is because every season has relative "trends" which makes it difficult to apply a general weightage for every season.

To fix this, I used Principle Component Analysis (PCA). This algorithm is unsupervised, meaning that it does not rely on given labels and instead finds the linear combination of weightages of features that explains the most variance in the data for each season independently. After normalizing the CB statistics, it is able to differentiate elite cornerbacks from average cornerbacks from worse-performing cornerbacks.

The way PCA works is by receiving a matrix of all features for all qualified CBs. It computes the first principal component, which is the direction in the feature space that captures the most variance between players. CBs are then given a score along this dimension which becomes their ranking score. Since all features are oriented so that higher values indicate better performance, the first principal component naturally aligns with overall coverage quality. A direction check is applied after each PCA run to ensure that components correlate correctly with elite cornerback performance.

Phase 6: Known Limitations

Though this model effectively uses statistics to provide viable cornerback rankings, there are some known limitations that are outside the scope of this project. The model treats all targets equally regardless of who the CB was covering. Better pass rushes create shorter release times for quarterbacks, making coverage easier and increasing the risk for big plays like interceptions or pass deflections.

Phase 7: Validation and Results

The model's results align closely with expert consensus and historical context. In 2020, Xavien Howard was #1, after leading the NFL with 10 interceptions and Jaire Alexander follows close behind with an elite season as well. In 2021, Jamel Dean had 4.8 yards per target and a 58.5 passer rating allowed, making his season elite by per-target metrics. In this season, Trevon Diggs did have elite INT numbers, but he also had a high yards per target rate of 8.8, making his ranking #10. To see the full rankings, go to the pigskin vision GitHub repository for the csv rankings.

Conclusion

This cornerback coverage model successfully addresses the core problem of CB evaluation: deriving meaningful performance rankings from a range of statistics. The model produces adaptive rankings based on the statistical environment of a season, without requiring any supervision. The model uses season-level normalization and unsupervised PCA to create expert-level rankings.

This model is especially reliable for recent years, as there is significantly more data on these seasons and statistical patterns are the most consistent as well. Though the model has limitations, it is a great stepping stone for future advancements in cornerback evaluation.
