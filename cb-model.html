Pigskin Vision: An Adaptive PCA Model for NFL Cornerback Evaluation

Abstract: A data-driven system for ranking NFL cornerbacks (2019–2025) using unsupervised Principal Component Analysis (PCA)[cite: 6, 8].

1. Problem Definition

Cornerback evaluation is difficult because elite performance is defined by "the absence of events"—passes not thrown[cite: 13, 14].

[IMAGE: THE TARGET GAP]

2. Data Selection

Standard data only tags defenders on 10.2% of pass plays[cite: 29, 32]. This model utilizes PFR Advanced stats which tracks every targeted pass[cite: 33, 35].

3. Feature Engineering

The model uses five per-target features[cite: 46]: Incompletion Rate, INT Rate, Passer Rating (Inv), Target Rate (Inv), and Yards Per Target (Inv).

4. Qualification Filters

Filtered to CBs with 40+ targets, 600+ snaps, and 13+ games to ensure statistical reliability[cite: 71, 74, 76, 80].
