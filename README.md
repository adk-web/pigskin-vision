# Pigskin Vision

**Teaching the next generation to watch football smarter.**

Pigskin Vision is an educational football analytics platform that uses
mathematics, data visualization, and machine learning to make advanced
football concepts easier to understand.

## What Pigskin Vision Does

Pigskin Vision is being developed around three ideas:

### Learn

Educational explanations connecting football strategy with statistics,
mathematics, and machine learning.

### Explore

Interactive visualizations that allow users to investigate football
data themselves.

### Discover

Research-inspired tools that use modern analytics and machine learning
to reveal patterns in football strategy.

## Current Status

Pigskin Vision is currently being rebuilt around its new educational
format.

The initial website provides the foundation for future:

- football analytics lessons
- mathematical explanations
- interactive data visualizations
- player tracking tools
- play similarity tools
- tactical archetype exploration
- machine learning demonstrations

## Technology

The website currently uses:

- HTML
- CSS
- JavaScript when interactive tools require it
- GitHub Pages

The project will add additional tools only when they are needed for
specific visualizations or analytics applications.
